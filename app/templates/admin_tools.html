How It Works

  • Promo codes work on the monthly Standard plan only.
  • Free days unlocks Standard immediately for the value entered.
  • Percent reduces the monthly price by that percentage.
  • Fixed amount subtracts that naira value from the monthly price.
  • Usage is counted only after activation or successful payment.
  • Each user and device can use the same code once.
